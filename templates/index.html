Search Parameters

Search by keyword, hashtag, or user account
For hashtags, the # symbol is optional. For users, the @ symbol is optional.
Maximum number of tweets to retrieve (1-1000)
Optional date range for filtering tweets

Command-Line Usage Examples

Search by Keyword
python twitter_scraper.py keyword "climate change" --limit 100 --start-date 2023-01-01 --end-date 2023-06-30 --lang en --format csv
Search by Hashtag
python twitter_scraper.py hashtag "AI" --limit 50 --format json
Search by User
python twitter_scraper.py user "elonmusk" --limit 200
